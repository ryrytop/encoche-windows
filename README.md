# Encoche pour Windows

L'encoche façon Dynamic Island, la barre du haut et le Dock du Mac, sur Windows 10 et 11.

## Installer

1. Télécharger la dernière version :
   - [Encoche.exe](https://github.com/ryrytop/encoche-windows/releases/latest/download/Encoche.exe) : pour la plupart des PC ;
   - [Encoche-ARM64.exe](https://github.com/ryrytop/encoche-windows/releases/latest/download/Encoche-ARM64.exe) : seulement pour les PC à puce Snapdragon / ARM.
2. Double-cliquer dessus. Si Windows affiche « Windows a protégé votre ordinateur », cliquer sur « Informations complémentaires », puis « Exécuter quand même ».
3. Encoche s'installe toute seule (sans mot de passe administrateur), se range dans le menu Démarrer et se lance au démarrage de Windows.

## Mises à jour

Encoche regarde ici toutes les 4 heures s'il y a une nouvelle version. Quand il y en a une, elle le propose : un clic sur « Effectuer la mise à jour » la télécharge depuis cette page, et Encoche se relance toute seule. Chaque version est signée : Encoche refuse un fichier qui ne vient pas d'ici.

On peut aussi vérifier à la main dans Réglages › À propos › « Rechercher une mise à jour ».

## Désinstaller

Paramètres de Windows › Applications › Applications installées › Encoche › Désinstaller.
